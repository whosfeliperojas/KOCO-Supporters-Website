PEKO & FRIENDS — IMAGE DROP FOLDER
===================================

Save the generated images here with EXACTLY these names and the app
will show them automatically (nothing appears until a file exists —
no code changes needed):

  peko-idle.webp        neutral, standing, small smile
  peko-wave.webp        waving hello            → dashboard greeting, login
  peko-celebrate.webp   celebrating, confetti   → idea submitted, points saved
  peko-think.webp       thinking, hand on chin  → while filling the form
  peko-point.webp       pointing to one side    → empty lists ("start here")
  peko-sad.webp         apologetic, droopy      → rejected content, errors
  peko-sleep.webp       sleeping, zzz           → no events scheduled

FORMAT
- WebP preferred (PNG also works if you rename the extension to .webp
  won't work — export/convert to real WebP, e.g. with squoosh.app)
- Transparent background
- Square canvas, ~600×600 px (the app scales them down)
- The full body inside the frame with a little margin

See docs/peko-prompts.txt for the ready-to-paste Nano Banana prompts.
